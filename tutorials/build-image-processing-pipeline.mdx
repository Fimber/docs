This tutorial walks you through preparing product photos for an e-commerce site. You will resize images to consistent dimensions, strip metadata that leaks location and device info, add a watermark, convert to WebP for smaller files, and combine everything into a single reusable command.

By the end, you will have a batch script that processes an entire folder of photos in one run.

<Info>
  This tutorial assumes you have ImageMagick installed and have run basic commands. If you haven't, start with [Getting started](/quickstart).
</Info>

<Info>
  **Shell:** Steps 1–5 use **bash** (Linux, macOS, or [Git for Windows](https://gitforwindows.org/) Git Bash). On **Windows PowerShell**, use the same `magick` commands by typing them on one line (omit the `\` line breaks), or follow the **Step 6** tab for batch loops in PowerShell.
</Info>

## Set up your working directory

Create a folder for this tutorial and add some test images:

```bash
mkdir -p pipeline/originals pipeline/processed
cd pipeline
```

If you have product photos on hand, copy them into `originals/`. If not, create three test images at different sizes to simulate real-world input:

```bash
magick -size 2400x1800 plasma:grey80-white originals/product1.jpg
magick -size 1800x2400 plasma:grey90-white originals/product2.jpg
magick -size 2000x2000 plasma:grey85-white originals/product3.jpg
```

These generate textured images at landscape (2400x1800), portrait (1800x2400), and square (2000x2000) dimensions. The exact content doesn't matter for this tutorial. What matters is that they are larger than the 800x800 target and arrive at inconsistent sizes.

Check their dimensions:

```bash
magick identify originals/*.jpg
```

Real product photos from different cameras and photographers arrive at different sizes. This pipeline standardizes them.

## Step 1: Resize to consistent dimensions

E-commerce platforms typically need images at a fixed maximum size. Resize a single image to fit within 800x800 pixels:

```bash
magick originals/product1.jpg -resize '800x800>' resized.jpg
magick identify resized.jpg
```

The `identify` output shows your 2400x1800 image is now 800x600. The resize step uses a trailing greater-than on the geometry so ImageMagick only shrinks: fit inside 800×800, keep aspect ratio, and never upscale a small source. Try the same resize on the other two images to see how portrait and square inputs behave.

The [geometry syntax reference](/reference/geometry) covers every modifier in detail.

## Step 2: Strip metadata

Photos from cameras and phones carry metadata that can include GPS coordinates, device info, and timestamps. For a public storefront, strip it:

```bash
magick originals/product1.jpg -strip stripped.jpg
magick identify stripped.jpg
```

The output file is the same image with all metadata removed. Confirm the file exists and check its dimensions before moving on.

## Step 3: Add a watermark

Watermarking has two parts: creating the watermark image and compositing it onto the product photo.

**Create the watermark.** This makes a transparent PNG with white text:

```bash
magick -size 300x60 xc:none \
  -fill white -pointsize 28 -gravity center \
  -annotate 0 "SAMPLE" \
  PNG32:watermark.png
```

You now have a `watermark.png` file with the word "SAMPLE" on a transparent background. The `PNG32:` prefix ensures the transparency is preserved in the output.

**Apply the watermark.** Composite it onto a product photo, positioned in the bottom-right corner:

```bash
magick originals/product1.jpg watermark.png \
  -gravity SouthEast -geometry +20+20 \
  -composite watermarked.jpg
magick identify watermarked.jpg
```

The `-gravity SouthEast -geometry +20+20` places the watermark 20 pixels from the bottom-right edges.

## Step 4: Convert to WebP

WebP produces smaller files than JPEG at comparable visual quality. Convert an image and set the compression level:

```bash
magick originals/product1.jpg -quality 85 product1.webp
magick identify product1.webp
```

ImageMagick picks the output format from the `.webp` extension. `-quality 85` is a good default for product photos.

## Step 5: Combine everything into one command

Each step you have learned so far is an operation that ImageMagick processes left to right. You can combine them all into a single `magick` call:

```bash
magick originals/product1.jpg \
  -resize '800x800>' \
  -strip \
  watermark.png \
  -gravity SouthEast -geometry +20+20 \
  -composite \
  -quality 85 \
  processed/product1.webp
```

Here is what happens at each stage of the command:

1. `originals/product1.jpg` loads the input image.
2. `-resize '800x800>'` shrinks it to fit within 800x800, preserving aspect ratio.
3. `-strip` removes all metadata.
4. `watermark.png` loads the watermark as a second image.
5. `-gravity SouthEast -geometry +20+20` positions the watermark at the bottom-right with a 20-pixel margin.
6. `-composite` merges the watermark onto the resized photo.
7. `-quality 85` sets the WebP compression level.
8. `processed/product1.webp` writes the final output.

Verify the result:

```bash
magick identify processed/product1.webp
```

One command takes a raw product photo and outputs a web-ready, watermarked, metadata-free WebP image.

## Step 6: Batch-process a folder

Wrap the pipeline in a loop to process every image in the `originals/` folder:

<Tabs>
  <Tab title="Linux / macOS">
    ```bash
    for file in originals/*.jpg; do
      filename=$(basename "$file" .jpg)
      magick "$file" \
        -resize '800x800>' \
        -strip \
        watermark.png \
        -gravity SouthEast -geometry +20+20 \
        -composite \
        -quality 85 \
        "processed/${filename}.webp"
      echo "Done: $file -> processed/${filename}.webp"
    done
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    Get-ChildItem originals\*.jpg | ForEach-Object {
      $outName = $_.BaseName + ".webp"
      magick $_.FullName `
        -resize "800x800>" `
        -strip `
        watermark.png `
        -gravity SouthEast -geometry +20+20 `
        -composite `
        -quality 85 `
        "processed\$outName"
      Write-Host "Done: $($_.Name) -> processed\$outName"
    }
    ```
  </Tab>
</Tabs>

After the loop finishes, check the results:

```bash
magick identify processed/*.webp
```

Each output image fits within 800x800, has no metadata, carries a watermark, and is compressed as WebP.

## Clean up

Remove the intermediate test files you created during the tutorial:

```bash
rm -f resized.jpg stripped.jpg watermarked.jpg product1.webp
```

Keep the `watermark.png`, `originals/`, and `processed/` folders. The watermark and the batch script are reusable for future product photo batches.

## What you learned

This tutorial covered six ImageMagick concepts through a single real-world task:

- **Resize with only-shrink geometry** (`-resize` plus `800x800>` in quotes) so large images fit inside 800×800 without upscaling smaller ones.
- **Metadata stripping** (`-strip`) to remove EXIF data including GPS coordinates and camera info.
- **Image creation** (`xc:none`, `-annotate`) to build a transparent watermark from scratch.
- **Compositing** (`-composite`, `-gravity`, `-geometry`) to overlay one image on another at a specific position.
- **Format conversion with quality control** (`-quality 85 output.webp`) to compress images for web delivery.
- **Operator chaining** to combine all five operations into a single command that processes an image in one pass.

From here, the [batch resize and optimize guide](/how-to/batch-resize-and-optimize) covers additional constraints like file size ceilings and handling mixed input formats. The [geometry syntax reference](/reference/geometry) documents every resize modifier.
