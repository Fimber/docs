New to ImageMagick? This page takes you from installation to your first working commands.

## Install ImageMagick

<Tabs>
  <Tab title="macOS">
    Install with [Homebrew](https://brew.sh):

    ```bash
    brew install imagemagick
    ```

    Homebrew bundles ImageMagick with delegates for JPEG, PNG, WebP, TIFF, and other common formats. For Ghostscript font support, also run:

    ```bash
    brew install ghostscript
    ```

    [MacPorts](https://www.macports.org/) (`sudo port install ImageMagick`) is an alternative if you prefer it.
  </Tab>
  <Tab title="Linux">
    Download the official AppImage from the [releases page](https://github.com/ImageMagick/ImageMagick/releases). The AppImage is a self-contained binary that requires no installation:

    ```bash
    wget https://github.com/ImageMagick/ImageMagick/releases/download/7.1.2-21/ImageMagick-7.1.2-21-gcc-x86_64.AppImage
    chmod +x ImageMagick-7.1.2-21-gcc-x86_64.AppImage
    sudo mv ImageMagick-7.1.2-21-gcc-x86_64.AppImage /usr/local/bin/magick
    ```

    On Ubuntu 26.04 and later, the `imagemagick` package from `apt` may include version 7. Check with `magick --version` after installing. On Ubuntu 24.04 and earlier, `apt install imagemagick` installs version 6. Use the AppImage above to get version 7.
  </Tab>
  <Tab title="Windows">
    Download the installer from the [ImageMagick releases page](https://imagemagick.org/script/download.php#windows). Choose the **Q16** variant (16 bits per channel) for most use cases.

    Run the installer and check **"Add application directory to your system path"** when prompted. This lets you run `magick` from any command prompt or PowerShell window.
  </Tab>
  <Tab title="Docker">
    The community-maintained [`dpokidov/imagemagick`](https://hub.docker.com/r/dpokidov/imagemagick) image provides ImageMagick 7 with broad format support. From their documentation:

    ```bash
    docker run --rm -v "$(pwd)":/imgs dpokidov/imagemagick /imgs/photo.jpg -resize 800x600 /imgs/resized.jpg
    ```

    This mounts your current directory into the container, processes the image, and writes the output back to your filesystem. See the [Docker Hub page](https://hub.docker.com/r/dpokidov/imagemagick) for additional usage examples and available tags.
  </Tab>
</Tabs>

## Verify the installation

Run:

```bash
magick --version
```

You should see the version number and a list of delegates (the image formats your build supports). The exact list varies by install method. A typical output looks like:

```
Version: ImageMagick 7.1.2-21 Q16-HDRI x86_64
Delegates (built-in): bzlib freetype jng jpeg png tiff webp xml zlib
```

If a format you need is missing from your delegates list (like `webp` or `heic`), you may need to install additional libraries and rebuild, or switch to a different install method that includes broader delegate support.

## Convert between formats

Convert a JPEG file to PNG:

```bash
magick photo.jpg photo.png
```

ImageMagick determines both input and output formats from the file extension. That single command decodes the JPEG, then re-encodes it as PNG.

## Resize an image

Shrink an image to fit within 800x600 pixels:

```bash
magick photo.jpg -resize 800x600 photo-small.jpg
```

The `-resize` operation preserves the original aspect ratio. A 1600x1200 input becomes 800x600. A 2000x1500 input becomes 800x600. A 1200x800 input becomes 800x533, because 800 is the limiting dimension at the 3:2 aspect ratio.

<Tip>
  Add `>` after the dimensions to skip images that are already small enough: `magick photo.jpg -resize 800x600\> photo-small.jpg`. Without the `>`, a 400x300 image would be enlarged to 800x600. With it, the image stays untouched.
</Tip>

## Inspect an image

Use `magick identify` to check an image's format, dimensions, and file size without opening it:

```bash
magick identify photo.jpg
```

Output:

```
photo.jpg JPEG 1600x1200 1600x1200+0+0 8-bit sRGB 11536B 0.000u 0:00.000
```

Reading left to right: filename, format, dimensions, geometry, bit depth, colorspace, file size.

For a cleaner view, use `-format` to pick the fields you want:

```bash
magick identify -format "Format: %m\nDimensions: %wx%h\nSize: %b\n" photo.jpg
```

Output:

```
Format: JPEG
Dimensions: 1600x1200
Size: 11536B
```

## Resize and compress in one command

Operations are processed left to right. You can stack several in one command:

```bash
magick photo.jpg -resize 800x600 -quality 80 photo-web.jpg
```

This resizes the image, then writes it as a JPEG at quality level 80 (lower means smaller file, more compression artifacts).

The order of **operators** matters. `-resize` followed by `-crop` produces a different result than `-crop` followed by `-resize`:

```bash
# Resize to 200x200, then crop the top-left 100x100
magick input.png -resize 200x200 -crop 100x100+0+0 +repage resize-then-crop.png

# Crop the top-left 100x100, then enlarge it to 200x200
magick input.png -crop 100x100+0+0 +repage -resize 200x200 crop-then-resize.png
```

The first command shrinks the whole image, then extracts a piece. The second command extracts a piece first, then enlarges that piece. Different order, different output.

<Info>
  **Settings vs. operators.** ImageMagick flags fall into two categories. Operators like `-resize`, `-crop`, and `-rotate` transform the image immediately at the point they appear in the command. Settings like `-gravity` and `-quality` change persistent state that remains in effect for the rest of the command. `-gravity Center` affects all spatial operators that follow it until you reset it. `-quality 80` sets the compression level used when the output file is written, so its position relative to operators does not change the result.
</Info>

## Process multiple files at once

Use `magick mogrify` to apply the same operation to every file matching a pattern:

```bash
magick mogrify -resize 400x300 *.jpg
```

<Warning>
  `mogrify` overwrites the original files. To write resized copies to a different folder, create the folder first, then use `-path`:

  ```bash
  mkdir resized
  magick mogrify -resize 400x300 -path resized *.jpg
  ```
</Warning>

## Keep going

You can now install, convert, resize, inspect, and batch-process images. For deeper reference material, see the official [ImageMagick command-line reference](https://imagemagick.org/script/command-line-options.php) and the [usage examples](https://imagemagick.org/Usage/).
