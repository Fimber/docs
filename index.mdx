ImageMagick is a scriptable image engine — run it in a terminal, call it from any language, or drop it into a CI pipeline. Convert, resize, composite, and filter images without a GUI, on any OS.

It ships on Linux, macOS, and Windows. These pages focus on **ImageMagick 7** and the `magick` driver command.

<Note>
  **v7 docs** — Migrating from v6? Standalone `convert` / `mogrify` are now invoked through `magick`. See the [v6 → v7 porting guide](https://imagemagick.org/script/porting.php).
</Note>

## Use cases

Each example is a single command you can copy; paths are placeholders.

### Square thumbnails from mixed aspect ratios

```bash
magick photo.jpg -resize 200x200^ -gravity center -extent 200x200 thumb.jpg
```

`-resize 200x200^` fills at least 200×200, then `-extent` crops to an exact square from the center.

### Batch convert a folder of JPEGs to WebP

```bash
mkdir -p web
magick mogrify -path web -format webp -quality 85 *.jpg
```

Writes WebP files into `web/` next to each JPEG basename. For subfolders, mixed formats, and `-auto-orient`, see the [batch resize guide](/how-to/batch-resize-and-optimize).

### Quick checks on an upload before you trust it

```bash
magick identify -verbose upload.png | grep -E 'Geometry|Format'
```

On **PowerShell**, use `Select-String` instead of `grep`:

```powershell
magick identify -verbose upload.png | Select-String -Pattern 'Geometry|Format'
```

## Run your first command

Convert a JPEG to PNG and resize it to fit inside 800×600 pixels, preserving aspect ratio:

```bash
magick photo.jpg -resize 800x600 photo.png
```

A 1200×800 input becomes 800×533. ImageMagick fits the image inside the target box without distortion, then picks the output format from the file extension.

Every command follows the same structure: **input**, then **operations** (left to right), then **output**.
