ImageMagick is a free, open-source toolkit for manipulating images from the command line. You can convert between formats, resize in batch, composite images together, apply filters, add text, and automate complex image pipelines with shell scripts or any programming language.

It runs on Linux, macOS, and Windows. Most Linux distributions and Homebrew on macOS include it in their package managers.

<Info>
  This documentation covers **ImageMagick 7** (the `magick` command). If you are migrating from version 6, the main change is that standalone commands like `convert`, `mogrify`, and `identify` are now subcommands of `magick`. For example, `convert input.jpg output.png` becomes `magick input.jpg output.png`. See the [v6 to v7 porting guide](https://imagemagick.org/script/porting.php) for full details.
</Info>

## What you can build with it

**Automate image pipelines for the web.** Convert uploads to WebP/AVIF, generate thumbnails at multiple sizes, and optimize file size as part of a build step or server-side script.

**Batch-process photos without a GUI.** Resize entire folders with `mogrify` or a shell loop, strip EXIF metadata for privacy, apply consistent watermarks, or convert between color profiles across thousands of files.

**Validate and constrain user uploads.** Enforce dimensions, reject unsupported formats, generate previews, and normalize images on servers that have no desktop environment.

## Run your first command

Convert a JPEG to PNG and resize it to fit within 800x600 pixels, preserving the aspect ratio:

```bash
magick photo.jpg -resize 800x600 photo.png
```

A 1200x800 input becomes 800x533. ImageMagick fits the image inside the target dimensions without distortion, then writes the result in the format implied by the output extension.

Every command follows the same structure: **input**, then **operations** (left to right), then **output**.
